# Sprint 3

- **Pondération** : 35%
- **Remise** : Le 12 mai 2026 au début du cours.

## Objectif

L'objectif de ce sprint est de compléter le développement de votre projet en
intégrant les fonctionnalités restantes. Vous devrez également intégrer dans
votre code les éléments nécessaires pour la présentation finale de votre
projet.

## Git et GitHub

Vous continuez d'utiliser Git et GitHub pour gérer votre projet.

## Grille d’évaluation

L'évaluation de ce sprint se concentrera principalement sur la qualité du code
en plus des autres critères d'évaluation habituels du sprint 2 et 3, sans les
besoins utilisateurs. L'évaluation tient aussi compte des modifications
apportées au projet pour la présentation finale.
